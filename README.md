# Shreed – Paper Reel Inventory Management System

Shreed is a Django-based web application developed to manage the inventory of paper reels for a stationery business.

## Features

- **Inventory Management:** Manage inventory records for paper reels.
- **Web-Based Interface:** Access the application through a browser.
- **Database Integration:** Store and manage inventory information using SQLite.

## Technologies Used

- **Language:** Python
- **Framework:** Django
- **Database:** SQLite
- **Frontend:** HTML, CSS
